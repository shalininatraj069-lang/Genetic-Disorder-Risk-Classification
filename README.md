# 🧬 Genetic Disorder Risk Classification System

## 📌 Project Overview
The Genetic Disorder Risk Classification System is a Machine Learning-based project developed to predict the category of genetic disorders using patient health information and genetic history.

This project uses the Logistic Regression algorithm to classify genetic disorders into different categories. A Streamlit web application is developed to allow users to enter patient information and view the model prediction.

**Note:** This project is developed for educational purposes only and is not intended for medical diagnosis.

## 🎯 Objectives
- To analyze genetic disorder-related patient data.
- To perform data preprocessing and exploratory data analysis.
- To develop a Machine Learning classification model.
- To predict genetic disorder categories using Logistic Regression.
- To deploy the model using a Streamlit web application.

## 🤖 Machine Learning Algorithm
**Logistic Regression**

Logistic Regression is a supervised Machine Learning algorithm used for classification problems. It predicts the genetic disorder category based on the input features.
